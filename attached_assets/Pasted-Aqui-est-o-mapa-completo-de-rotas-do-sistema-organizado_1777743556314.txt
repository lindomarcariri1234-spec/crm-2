Resumo da hierarquia de acesso:

superadmin  →  acesso total (plataforma + todos os tenants)
agencia     →  acesso total dentro do próprio tenant
gerente     →  gestão ampla, sem exclusões críticas
suporte     →  operacional, sem financeiro ou equipe
vendedor    →  foco em clientes e reservas
cliente     →  somente storefront público
público     →  somente vitrine e checkout


superadmin  →  acesso total (plataforma + todos os tenants) O usuário com permissão superadmin é criado diretamente no código do projeto.
agencia     →  acesso total dentro do próprio tenant  O usuário com permissão agencia é criado na pagina de /sign-in	Login (Clerk) e /sign-up	Cadastro (Clerk).
gerente     →  gestão ampla, sem exclusões críticas   O usuário com permissão gerente é criado pela a Agência na página Configurações Aba equipe.
suporte     →  operacional, sem financeiro ou equipe  O usuário com permissão suporte é criado pela a Agência na página Configurações Aba equipe.
vendedor    →  foco em clientes e reservas    O usuário com permissão vendedor é criado pela a Agência na página Configurações Aba equipe.
cliente     →  somente storefront público   O usuário com permissão cliente é criado no ato da reserva.
público     →  somente vitrine e checkout

Criar Dashboard

Usuário superadmin já foi criado o Dashboard OK
Usuário agencia já foi criado o Dashboard OK
Usuário gerente já foi criado o Dashboard OK
Usuário suporte já foi criado o Dashboard OK
Usuário vendedor já foi criado o Dashboard OK
Usuário cliente precisa criar um Painel de Cliente com informações referente ao Cliente


Após a finalização da reserva, o cliente pode clicar no menu superior com o seguinte nome Meu Perfil, e entrará no Painel do cliente para visualizar as informações referentes ao perfil de cliente.
O painel do cliente deverá conter apenas informações referente ao cliente.
O Cliente NÃO pode ter acesso ao Dashboard do:
Usuário superadmin
Usuário agencia
Usuário gerente
Usuário suporte
Usuário vendedor
