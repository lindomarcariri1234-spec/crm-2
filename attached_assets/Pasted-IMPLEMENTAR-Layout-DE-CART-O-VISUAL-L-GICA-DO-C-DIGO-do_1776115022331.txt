IMPLEMENTAR Layout DE CARTÃO VISUAL + LÓGICA DO CÓDIGO do dashboard do cliente (Painel do cliente):

🧩 1. Estrutura Geral do Layout
Formato: Horizontal padrão (similar a cartões reais)
Inclinação: Levemente rotacionado → efeito premium e dinâmico
Profundidade: Sombra inferior + glow → sensação de cartão físico flutuando
Bordas: Arredondadas e suaves → estética moderna
🌈 2. Fundo e Identidade Visual
Gradiente: Roxo → azul → preto
Iluminação: Feixes de luz diagonais (efeito futurista)
Textura: Lisa com brilho suave (luxo discreto)

📌 Função: transmitir tecnologia, exclusividade e sofisticação

🔠 3. PREFIXO DA AGÊNCIA (CHQ)
📍 Posição:
Canto superior esquerdo
🎨 Elemento:
Logo + sigla “CHQ”
Cor branca (alto contraste com fundo escuro)
Destaque com um balão explicativo:
👉 “Prefixo da Agência (3 letras)”
🧠 Função no sistema:
Identifica a origem (agência/empresa)
Exemplo:
CHQ → Chiquinha Turismo
Pode escalar para outras marcas no futuro
🏷️ 4. TIPO DO PRODUTO (EXC / PCT / BTV)
📍 Posição:
Lateral direita do cartão (em pé/vertical)
Próximo à borda direita
🎨 Elemento:
Texto “EXC” em destaque
Indicador lateral com texto explicativo:
👉 “Tipo (EXC/PCT/BTV)”
🧠 Função no sistema:

Define o tipo de serviço:

EXC → Excursão
PCT → Pacote
BTV → Bate-volta

📌 Insight: isso transforma o cartão em um identificador inteligente de produto

🔢 5. NÚMERO PRINCIPAL DO CARTÃO (COM CÓDIGO EMBUTIDO)
📍 Posição:
Centro do cartão (horizontal)
🎨 Formato exibido:

1234 202604-00001 3456

🧠 Estrutura interna (ESSENCIAL):
🔹 202604 → Ano/Mês
2026 = Ano
04 = Abril

📌 Indica quando a venda/reserva foi gerada

🔹 00001 → Sequencial
Contador de vendas do mês
Sempre com 5 dígitos
Reinicia todo mês

📌 Exemplo:

00001 → primeira venda do mês
00057 → quinquagésima sétima venda
💡 Resumo da linha central:

O número do cartão não é só estético — ele é um ID inteligente integrado ao sistema CRM

  sequence: number // 1

  clientCpf?: string
  
  // Dados da Viagem
  tripTitle: string
  destination: string
  departureDate: string
  
  // Assento
  seatNumber: string
  
  // Voucher
  voucherCode: string
  
  // Agência
  agencyName: string
  agencyLogo?: string
  
  // Status
  status: 'pending' | 'confirmed' | 'cancelled'
  paymentStatus: 'pending' | 'partial' | 'paid'
  
  // Valores
  totalAmount: number
  amountPaid: number
}

export function ReservationCardVisual({
  reservationNumber,
  prefix,
  typeCode,
  yearMonth,
  sequence,
  clientName,
  clientCpf,
  tripTitle,
  destination,
  departureDate,
  seatNumber,

  status,

    const colors = {
      pending: 'bg-yellow-500',
      confirmed: 'bg-green-500',
      cancelled: 'bg-red-500',

    return colors[status]
  }

      {/* Container com perspectiva para efeito 3D */}

          {/* FRENTE DO CARTÃO */}

          <div

              absolute inset-0 backface-hidden
              rounded-2xl shadow-2xl overflow-hidden
              bg-gradient-to-br from-[#667eea] via-[#764ba2] to-[#1a1a2e]
              transform hover:scale-105 transition-transform duration-300
              cursor-pointer
            `}
            style={{
              transform: 'rotateX(5deg) rotateY(-5deg)',
              boxShadow: '0 25px 50px -12px rgba(0, 0, 0, 0.5), 0 0 40px rgba(102, 126, 234, 0.3)',
            }}
          >
            {/* Efeitos de Luz de Fundo */}
            <div className="absolute inset-0 opacity-30">
              <div className="absolute top-0 right-0 w-96 h-96 bg-white rounded-full blur-3xl transform translate-x-1/2 -translate-y-1/2" />
              <div className="absolute bottom-0 left-0 w-64 h-64 bg-purple-300 rounded-full blur-3xl transform -translate-x-1/2 translate-y-1/2" />
              
              {/* Feixes de luz diagonais */}
              <div className="absolute inset-0 bg-gradient-to-br from-transparent via-white/10 to-transparent transform rotate-12" />
            </div>

            {/* Conteúdo do Cartão */}
            <div className="relative z-10 h-full p-6 flex flex-col justify-between text-white">
              
              {/* ═══════════════════════════════════════════════════════════ */}
              {/* HEADER: Logo + Prefixo + NFC */}
              {/* ═══════════════════════════════════════════════════════════ */}
              <div className="flex items-start justify-between">
                {/* Logo + Prefixo da Agência */}
                <TooltipProvider>
                  <Tooltip>
                    <TooltipTrigger asChild>
                      <div className="flex items-center gap-3 cursor-help">
                        {agencyLogo ? (
                          <img src={agencyLogo} alt={agencyName} className="w-12 h-12 rounded-lg" />
                        ) : (
                          <div className="w-12 h-12 bg-white/20 backdrop-blur-sm rounded-lg flex items-center justify-center">
                            <CreditCard className="w-7 h-7" />

                        <div>
                          <p className="text-2xl font-bold tracking-wider">{prefix}</p>
                          <p className="text-xs opacity-80">{agencyName}</p>
                        </div>
                      </div>
                    </TooltipTrigger>
                    <TooltipContent side="bottom" className="bg-gray-900 text-white">
                      <p className="font-semibold">Prefixo da Agência (3 letras)</p>
                      <p className="text-xs opacity-80">Identifica a origem da reserva</p>
                    </TooltipContent>

                {/* NFC Icon + Status */}
                <div className="flex flex-col items-end gap-2">

                </div>
              </div>

              {/* ═══════════════════════════════════════════════════════════ */}

                  </div>
                </div>
              </div>

              {/* ═══════════════════════════════════════════════════════════ */}

                </Tooltip>
              </TooltipProvider>

              {/* ═══════════════════════════════════════════════════════════ */}

                <div>

// app/(client)/minha-conta/reservas/[id]/page.tsx

import { getServerSession } from 'next-auth'
import { authOptions } from '@/lib/auth'
import { prisma } from '@/lib/prisma'
import { ReservationCardVisual } from '@/components/client-dashboard/reservation-card-visual'
import { parseReservationNumber } from '@/lib/reservations/generate-number-complete'
import { format } from 'date-fns'
import { ptBR } from 'date-fns/locale'
import { redirect } from 'next/navigation'

export default async function ClientReservationPage({
  params,
}: {
  params: { id: string }
}) {
  const session = await getServerSession(authOptions)

  if (!session) {
    redirect('/login')
  }

  // Buscar reserva do cliente
  const reservation = await prisma.reservation.findFirst({
    where: {
      id: params.id,
      client_id: session.user.clientId, // Apenas reservas do próprio cliente
    },
    include: {
      client: true,
      trip: true,
      seats: {
        orderBy: { seat_number: 'asc' },
      },
      tenant: true,
      payments: true,
    },
  })

  if (!reservation) {
    return (
      <div className="container mx-auto py-12 text-center">
        <h1 className="text-2xl font-bold text-gray-800">Reserva não encontrada</h1>
        <p className="text-gray-600 mt-2">Esta reserva não existe ou você não tem permissão para visualizá-la.</p>
      </div>
    )
  }

  // Parsear número da reserva
  const numberData = parseReservationNumber(reservation.reservation_number)

  // Formatar data
  const departureDate = format(
    new Date(reservation.departure_date),
    "dd/MM/yyyy",
    { locale: ptBR }
  )

  // Calcular valor pago
  const amountPaid = reservation.payments?.reduce(
    (sum, payment) => sum + Number(payment.amount),
    0
  ) || 0

  return (
    <div className="min-h-screen bg-gradient-to-br from-gray-50 to-gray-100 py-12">
      <div className="container mx-auto px-4">
        {/* Header */}
        <div className="text-center mb-8">
          <h1 className="text-3xl font-bold text-gray-800 mb-2">
            Minha Reserva
          </h1>
          <p className="text-gray-600">
            {reservation.trip.title}
          </p>
        </div>

        {/* Cartão Visual */}
        <ReservationCardVisual
          reservationNumber={reservation.reservation_number}
          prefix={numberData.prefix}
          typeCode={numberData.typeCode}
          yearMonth={numberData.yearMonth}
          sequence={numberData.sequence}
          clientName={reservation.client_name}
          clientCpf={reservation.client_cpf}
          tripTitle={reservation.trip.title}
          destination={reservation.trip.destination}
          departureDate={departureDate}
          seatNumber={reservation.seats[0]?.seat_number || '-'}
          voucherCode={reservation.voucher_code}
          agencyName={reservation.tenant.name}
          agencyLogo={reservation.tenant.logo_url}
          status={reservation.status as 'pending' | 'confirmed' | 'cancelled'}
          paymentStatus={reservation.payment_status as 'pending' | 'partial' | 'paid'}
          totalAmount={Number(reservation.total_amount)}
          amountPaid={amountPaid}
        />

        {/* Detalhes da Viagem */}
        <div className="mt-12 max-w-2xl mx-auto">
          <div className="bg-white rounded-xl shadow-lg p-6 space-y-6">
            <h2 className="text-2xl font-bold text-gray-800">Detalhes da Viagem</h2>

            <div className="grid grid-cols-1 md:grid-cols-2 gap-6">
              <div>
                <p className="text-sm text-gray-600 mb-1">Destino</p>
                <p className="text-lg font-semibold text-gray-800">
                  {reservation.trip.destination}
                </p>
              </div>

              <div>
                <p className="text-sm text-gray-600 mb-1">Data de Saída</p>
                <p className="text-lg font-semibold text-gray-800">
                  {format(new Date(reservation.departure_date), "dd/MM/yyyy 'às' HH:mm", {
                    locale: ptBR,
                  })}
                </p>
              </div>

              <div>
                <p className="text-sm text-gray-600 mb-1">Passageiros</p>
                <p className="text-lg font-semibold text-gray-800">
                  {reservation.total_passengers}
                </p>
              </div>

              <div>
                <p className="text-sm text-gray-600 mb-1">Assentos</p>
                <div className="flex flex-wrap gap-2">
                  {reservation.seats.map((seat) => (
                    <span
                      key={seat.id}
                      className="px-3 py-1 bg-orange-500 text-white rounded-full text-sm font-semibold"
                    >
                      {seat.seat_number}
                    </span>
                  ))}
                </div>
              </div>
            </div>

            {/* Informações de Pagamento */}
            <div className="border-t pt-6">
              <h3 className="text-xl font-bold text-gray-800 mb-4">Pagamento</h3>
              
              <div className="space-y-3">
                <div className="flex justify-between">
                  <span className="text-gray-600">Subtotal:</span>
                  <span className="font-semibold">
                    R$ {Number(reservation.subtotal_amount).toFixed(2)}
                  </span>
                </div>

                {Number(reservation.discount_amount) > 0 && (
                  <div className="flex justify-between text-green-600">
                    <span>Desconto:</span>
                    <span className="font-semibold">
                      - R$ {Number(reservation.discount_amount).toFixed(2)}
                    </span>
                  </div>
                )}

                <div className="flex justify-between text-lg font-bold border-t pt-3">
                  <span>Total:</span>
                  <span className="text-green-600">
                    R$ {Number(reservation.total_amount).toFixed(2)}
                  </span>
                </div>

                <div className="flex justify-between">
                  <span className="text-gray-600">Pago:</span>
                  <span className="font-semibold text-blue-600">
                    R$ {amountPaid.toFixed(2)}
                  </span>
                </div>

                <div className="flex justify-between">
                  <span className="text-gray-600">Pendente:</span>
                  <span className="font-semibold text-orange-600">
                    R$ {Number(reservation.amount_pending).toFixed(2)}
                  </span>
                </div>
              </div>
            </div>
          </div>
        </div>
      </div>
    </div>
  )
}
