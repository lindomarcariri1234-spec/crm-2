# 🧭 VISÃO GERAL — O QUE É O “LAYOUT DE ASSENTOS”

O Layout de Assentos é um **módulo visual e operacional** que representa graficamente os lugares disponíveis em um veículo (ônibus, van, micro, etc.), permitindo:

* Controle de ocupação
* Venda organizada
* Escolha de assento pelo cliente
* Gestão em tempo real

Esse tipo de sistema é considerado padrão moderno no turismo rodoviário. ([Viagilize][1])

---

# 🧱 ESTRUTURA COMPLETA DO LAYOUT DE ASSENTOS

## 1. CONFIGURAÇÃO DO VEÍCULO

Aqui você define a base estrutural do layout:

### 🔹 Tipo de veículo

* Ônibus convencional
* Micro-ônibus
* Van / Sprinter
* Double Decker (2 andares)

### 🔹 Quantidade de assentos

* Total de poltronas (ex: 46 lugares)
* Distribuição por fileiras

### 🔹 Estrutura interna

* Corredor central (sim/não)
* Número de colunas (2x2, 2x1, etc.)
* Andares (no caso de DD)

👉 Isso permite criar layouts personalizados para qualquer tipo de operação.

---

## 2. CRIAÇÃO DO MAPA VISUAL

É o coração do sistema.

### 🔹 Representação gráfica

* Assentos como “blocos clicáveis”
* Identificação por número (1, 2, 3…)
* Organização por fileiras

### 🔹 Elementos visuais adicionais

* Motorista (posição frontal)
* Porta de entrada
* Banheiro (se houver)
* Escadas (ônibus DD)

### 🔹 Orientação

* Frente do veículo claramente indicada
* Sentido da viagem

👉 Isso transforma o controle em algo visual e intuitivo (tipo mapa de avião).

---

## 3. STATUS DOS ASSENTOS (CORES E ESTADOS)

Cada assento possui um status com cor específica:

* 🟢 Disponível
* 🔴 Ocupado (vendido)
* 🟡 Reservado (pré-venda)
* ⚫ Bloqueado (uso interno/manutenção)

Esse controle evita erros graves como venda duplicada. ([Viagilize][1])

---

## 4. INTERAÇÃO (BACKOFFICE E CLIENTE)

### 🔹 Para o operador (agência)

* Selecionar assento manualmente
* Reservar temporariamente
* Bloquear assentos específicos
* Visualizar ocupação em tempo real

### 🔹 Para o cliente (checkout)

* Escolher o assento diretamente
* Visualizar mapa antes de comprar
* Experiência similar a compra de passagem aérea

👉 Isso aumenta percepção de valor e conversão.

---

## 5. REGRAS E CONFIGURAÇÕES AVANÇADAS

### 🔹 Regras de venda

* Limite de assentos por cliente
* Assentos exclusivos (ex: guia, motorista)
* Assentos premium (ex: primeira fila)

### 🔹 Bloqueios automáticos

* Assentos quebrados
* Distanciamento (quando necessário)
* Uso operacional

### 🔹 Liberação automática

* Reservas expiram após X minutos
* Retorno automático para “disponível”

---

## 6. SINCRONIZAÇÃO EM TEMPO REAL

* Atualização instantânea
* Evita conflito de vendas simultâneas
* Integração com:

  * Checkout
  * CRM
  * Financeiro

👉 Dois clientes não conseguem comprar o mesmo assento ao mesmo tempo.

---

## 7. PERSONALIZAÇÃO DO LAYOUT

### 🔹 Customização completa

* Criar layout do zero
* Definir número de fileiras
* Ajustar espaçamento

### 🔹 Templates prontos

* Ônibus padrão
* DD (dois andares)
* Vans

👉 Flexibilidade total para diferentes tipos de excursão.

---

## 8. VINCULAÇÃO COM A VIAGEM

Cada layout está ligado a:

* Uma excursão específica
* Data da viagem
* Veículo utilizado

Ou seja:
👉 O mesmo ônibus pode ter layouts diferentes por viagem (dependendo da configuração).

---

## 9. RELATÓRIOS E CONTROLE

* Taxa de ocupação (%)
* Assentos vendidos vs disponíveis
* Mapa geral da viagem
* Lista de passageiros por assento

model VehicleLayout {
  id              String    @id @default(cuid())
  tenant_id       String
  tenant          Tenant    @relation(fields: [tenant_id], references: [id], onDelete: Cascade)
  
  // INFORMAÇÕES BÁSICAS
  name            String    // "Ônibus Executivo 46 lugares"
  description     String?   @db.Text
  
  // TIPO DE VEÍCULO
  vehicle_type    String    // bus, microbus, van, double_decker
  
  // DIMENSÕES DO GRID
  rows            Int       // Número de fileiras
  columns         Int       // Número de colunas
  floors          Int       @default(1) // Andares (1 ou 2)
  
  // CAPACIDADE
  total_seats     Int       // Total de assentos
  total_wc        Int       @default(0)
  total_stairs    Int       @default(0)
  total_fridge    Int       @default(0)
  
  // CONFIGURAÇÕES
  has_corridor    Boolean   @default(true)
  numbering_type  String    @default("sequential") // sequential, by_row, custom
  
  // TEMPLATE
  is_template     Boolean   @default(false) // Se é modelo reutilizável
  is_default      Boolean   @default(false) // Layout padrão do tenant
  
  // STATUS
  status          String    @default("active") // active, inactive, archived
  
  // RELACIONAMENTOS
  seats           VehicleSeat[]
  trips           Trip[]
  
  created_at      DateTime  @default(now())
  updated_at      DateTime  @updatedAt
  created_by      String?
  
  @@index([tenant_id])
  @@index([tenant_id, is_template])
  @@index([tenant_id, is_default])
  @@map("vehicle_layouts")
}

  floor           Int       @default(1) // Andar (1 ou 2)

  is_vip          Boolean   @default(false)

  // PREÇO ADICIONAL

  @@unique([layout_id, row, column, floor])
  @@index([layout_id])
  @@index([layout_id, type])

}

'use client'

import { useState, useEffect } from 'react'

  Minus,
  Save,
  ArrowLeft,
} from 'lucide-react'
import { useRouter } from 'next/navigation'
import { Badge } from '@/components/ui/badge'

interface SeatElement {
  row: number
  column: number
  floor: number
  type: 'seat' | 'wc' | 'stairs' | 'fridge' | 'empty' | 'driver'
  number?: string
  isVip?: boolean
  isAccessible?: boolean
  isBlocked?: boolean
  isPremium?: boolean
  extraPrice?: number
  notes?: string
}

export function LayoutBuilder({ layoutId }: { layoutId?: string }) {
  const router = useRouter()
  
  // Estado do Layout
  const [name, setName] = useState('')
  const [vehicleType, setVehicleType] = useState('bus')
  const [rows, setRows] = useState(12)
  const [columns, setColumns] = useState(4)
  const [floors, setFloors] = useState(1)
  const [grid, setGrid] = useState<SeatElement[][]>([])
  const [selectedTool, setSelectedTool] = useState<SeatElement['type']>('seat')
  const [currentFloor, setCurrentFloor] = useState(1)
  const [isSaving, setIsSaving] = useState(false)

  // Inicializar grid
  useEffect(() => {
    initializeGrid()
  }, [rows, columns, floors])

  const initializeGrid = () => {
    const newGrid: SeatElement[][] = []
    
    for (let row = 0; row < rows; row++) {
      newGrid[row] = []
      for (let col = 0; col < columns; col++) {
        newGrid[row][col] = {
          row,
          column: col,
          floor: currentFloor,
          type: 'empty',
        }
      }
    }
    
    setGrid(newGrid)
  }

  // Aplicar template pré-definido
  const applyTemplate = (template: string) => {
    switch (template) {
      case 'bus_46':
        setRows(12)
        setColumns(4)
        setFloors(1)
        applyBus46Template()
        break
      case 'microbus':
        setRows(8)
        setColumns(4)
        setFloors(1)
        break
      case 'van':
        setRows(5)
        setColumns(3)
        setFloors(1)
        break
      case 'double_decker':
        setRows(12)
        setColumns(4)
        setFloors(2)
        break
    }
  }

  const applyBus46Template = () => {
    const newGrid: SeatElement[][] = []
    let seatNumber = 1

    for (let row = 0; row < 12; row++) {
      newGrid[row] = []
      
      for (let col = 0; col < 4; col++) {
        // Primeira fileira: motorista
        if (row === 0 && col === 0) {
          newGrid[row][col] = {
            row,
            column: col,
            floor: 1,
            type: 'driver',
          }
        }
        // Última fileira: WC
        else if (row === 11 && col >= 2) {
          newGrid[row][col] = {
            row,
            column: col,
            floor: 1,
            type: 'wc',
          }
        }
        // Corredor (coluna 2)
        else if (col === 2) {
          newGrid[row][col] = {
            row,
            column: col,
            floor: 1,
            type: 'empty',
          }
        }
        // Assentos normais
        else {
          newGrid[row][col] = {
            row,
            column: col,
            floor: 1,
            type: 'seat',
            number: String(seatNumber++),
          }
        }
      }
    }

    setGrid(newGrid)
  }

  // Clicar em célula
  const handleCellClick = (row: number, col: number) => {
    const newGrid = [...grid]
    
    if (selectedTool === 'seat') {
      const seatNumber = calculateSeatNumber()
      newGrid[row][col] = {
        row,
        column: col,
        floor: currentFloor,
        type: 'seat',
        number: seatNumber,
      }
    } else {
      newGrid[row][col] = {
        row,
        column: col,
        floor: currentFloor,
        type: selectedTool,
      }
    }
    
    setGrid(newGrid)
  }

  // Calcular número do assento
  const calculateSeatNumber = () => {
    const seats = grid.flat().filter((cell) => cell.type === 'seat')
    return String(seats.length + 1)
  }

  // Estatísticas
  const stats = {
    seats: grid.flat().filter((c) => c.type === 'seat').length,
    wc: grid.flat().filter((c) => c.type === 'wc').length,
    stairs: grid.flat().filter((c) => c.type === 'stairs').length,
    fridge: grid.flat().filter((c) => c.type === 'fridge').length,
  }

  // Salvar layout
  const handleSave = async () => {
    setIsSaving(true)

    try {
      const response = await fetch('/api/dashboard/layouts', {
        method: layoutId ? 'PUT' : 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          id: layoutId,
          name,
          vehicleType,
          rows,
          columns,
          floors,
          grid,
        }),
      })

      if (response.ok) {
        router.push('/dashboard/layouts')
      }
    } catch (error) {
      console.error('Erro ao salvar layout:', error)
    } finally {
      setIsSaving(false)
    }
  }

  return (
    <div className="min-h-screen bg-gray-50 py-8">
      <div className="container mx-auto px-4">
        {/* Header */}
        <div className="flex items-center justify-between mb-8">
          <div className="flex items-center gap-4">
            <Button
              variant="ghost"

// Componente de Célula do Grid
function SeatCell({
  cell,
  onClick,
}: {
  cell: SeatElement
  onClick: () => void
}) {
  const getColor = () => {
    switch (cell.type) {
      case 'seat':
        return 'bg-blue-500 hover:bg-blue-600 text-white'
      case 'wc':
        return 'bg-purple-500 hover:bg-purple-600 text-white'
      case 'stairs':
        return 'bg-gray-800 hover:bg-gray-900 text-white'
      case 'fridge':
        return 'bg-cyan-500 hover:bg-cyan-600 text-white'
      case 'driver':
        return 'bg-yellow-500 hover:bg-yellow-600 text-white'
      case 'empty':
        return 'bg-gray-100 hover:bg-gray-200 border border-gray-300'
    }
  }

  const getIcon = () => {
    switch (cell.type) {
      case 'seat':
        return <Armchair className="h-4 w-4" />
      case 'wc':
        return <Toilet className="h-4 w-4" />
      case 'stairs':
        return <Stairs className="h-4 w-4" />
      case 'fridge':
        return <Refrigerator className="h-4 w-4" />
      default:
        return null
    }
  }

  return (
    <button
      onClick={onClick}
      className={`
        w-14 h-14 rounded-lg flex flex-col items-center justify-center
        transition-all duration-200 cursor-pointer
        ${getColor()}
      `}
    >
      {getIcon()}
      {cell.number && (
        <span className="text-xs font-bold mt-1">{cell.number}</span>
      )}
    </button>
  )
}

// Listar layouts
export async function GET(req: Request) {
  try {
    const session = await getServerSession(authOptions)

    if (!session) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 })
    }

    const layouts = await prisma.vehicleLayout.findMany({
      where: {
        tenant_id: session.user.tenantId,
        status: 'active',
      },
      include: {
        seats: true,
        _count: {
          select: {
            trips: true,
          },
        },
      },
      orderBy: {
        created_at: 'desc',
      },
    })

    return NextResponse.json({ layouts })
  } catch (error) {
    console.error('Erro ao buscar layouts:', error)
    return NextResponse.json(
      { error: 'Erro ao buscar layouts' },
      { status: 500 }
    )
  }
}

// Criar layout
export async function POST(req: Request) {
  try {
    const session = await getServerSession(authOptions)

    if (!session) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 })
    }

    const { name, vehicleType, rows, columns, floors, grid } = await req.json()

    // Validações
    if (!name || !vehicleType || !rows || !columns || !grid) {
      return NextResponse.json(
        { error: 'Dados incompletos' },
        { status: 400 }
      )
    }

    // Calcular estatísticas
    const flatGrid = grid.flat()
    const totalSeats = flatGrid.filter((c: any) => c.type === 'seat').length
    const totalWC = flatGrid.filter((c: any) => c.type === 'wc').length
    const totalStairs = flatGrid.filter((c: any) => c.type === 'stairs').length
    const totalFridge = flatGrid.filter((c: any) => c.type === 'fridge').length

    // Criar layout
    const layout = await prisma.vehicleLayout.create({
      data: {
        tenant_id: session.user.tenantId,
        name,
        vehicle_type: vehicleType,
        rows,
        columns,
        floors,
        total_seats: totalSeats,
        total_wc: totalWC,
        total_stairs: totalStairs,
        total_fridge: totalFridge,
        created_by: session.user.id,
      },
    })

    // Criar assentos
    for (const row of grid) {
      for (const cell of row) {
        if (cell.type !== 'empty') {
          await prisma.vehicleSeat.create({
            data: {
              layout_id: layout.id,
              row: cell.row,
              column: cell.column,
              floor: cell.floor,
              type: cell.type,
              number: cell.number,
              is_vip: cell.isVip || false,
              is_accessible: cell.isAccessible || false,
              is_blocked: cell.isBlocked || false,
              is_premium: cell.isPremium || false,
              extra_price: cell.extraPrice || 0,
              notes: cell.notes,
            },
          })
        }
      }
    }

    return NextResponse.json({ layout })
  } catch (error) {
    console.error('Erro ao criar layout:', error)
    return NextResponse.json(
      { error: 'Erro ao criar layout' },
      { status: 500 }
    )
  }
}

// app/api/public/trips/[tripId]/seats/route.ts

import { NextResponse } from 'next/server'
import { prisma } from '@/lib/prisma'

/**
 * Retorna disponibilidade de assentos em tempo real
 */
export async function GET(
  req: Request,
  { params }: { params: { tripId: string } }
) {
  try {
    const { searchParams } = new URL(req.url)
    const itineraryId = searchParams.get('itinerary_id')

    if (!itineraryId) {
      return NextResponse.json(
        { error: 'itinerary_id é obrigatório' },
        { status: 400 }
      )
    }

    // Buscar viagem com layout
    const trip = await prisma.trip.findUnique({
      where: { id: params.tripId },
      include: {
        layout: {
          include: {
            seats: {
              orderBy: [
                { floor: 'asc' },
                { row: 'asc' },
                { column: 'asc' },
              ],
            },
          },
        },
      },
    })

    if (!trip) {
      return NextResponse.json(
        { error: 'Viagem não encontrada' },
        { status: 404 }
      )
    }

    if (!trip.layout) {
      return NextResponse.json(
        { error: 'Layout não configurado para esta viagem' },
        { status: 400 }
      )
    }

    // Buscar assentos ocupados/reservados
    const occupiedSeats = await prisma.reservationSeat.findMany({
      where: {
        trip_id: params.tripId,
        itinerary_id: itineraryId,
        status: {
          in: ['reserved', 'confirmed', 'checked_in'],
        },
        OR: [
          // Confirmados
          { status: { in: ['confirmed', 'checked_in'] } },
          // Reservados e ainda válidos
          {
            status: 'reserved',
            reserved_until: {
              gte: new Date(),
            },
          },
        ],
      },
      select: {
        seat_number: true,
        status: true,
        reserved_until: true,
      },
    })

    // Mapear status de cada assento
    const seatsWithStatus = trip.layout.seats.map((seat) => {
      const occupied = occupiedSeats.find((os) => os.seat_number === seat.number)

      return {
        id: seat.id,
        number: seat.number,
        row: seat.row,
        column: seat.column,
        floor: seat.floor,
        type: seat.type,
        isVip: seat.is_vip,
        isAccessible: seat.is_accessible,
        isPremium: seat.is_premium,
        isBlocked: seat.is_blocked,
        extraPrice: Number(seat.extra_price),
        notes: seat.notes,
        // Status de disponibilidade
        status: occupied
          ? occupied.status === 'reserved'
            ? 'reserved'
            : 'occupied'
          : seat.is_blocked
          ? 'blocked'
          : 'available',
        reservedUntil: occupied?.reserved_until,
      }
    })

    return NextResponse.json({
      layout: {
        id: trip.layout.id,
        name: trip.layout.name,
        rows: trip.layout.rows,
        columns: trip.layout.columns,
        floors: trip.layout.floors,
        vehicleType: trip.layout.vehicle_type,
      },
      seats: seatsWithStatus,
      basePrice: Number(trip.promotional_price || trip.price_per_person),
    })
  } catch (error) {
    console.error('Erro ao buscar assentos:', error)
    return NextResponse.json(
      { error: 'Erro ao buscar assentos' },
      { status: 500 }
    )
  }
}

'use client'

import { useState, useEffect } from 'react'
import { Card } from '@/components/ui/card'

import { Badge } from '@/components/ui/badge'

import { Alert, AlertDescription } from '@/components/ui/alert'

interface Seat {
  id: string
  number: string
  row: number
  column: number
  floor: number
  type: 'seat' | 'wc' | 'stairs' | 'fridge' | 'driver' | 'empty'
  isVip: boolean
  isAccessible: boolean
  isPremium: boolean
  isBlocked: boolean
  extraPrice: number
  notes?: string
  status: 'available' | 'occupied' | 'reserved' | 'blocked'
  reservedUntil?: Date
}

interface SeatSelectionMapProps {
  tripId: string
  itineraryId: string
  maxSeats: number
  basePrice: number
  onSelectionChange: (selectedSeats: string[], totalPrice: number) => void
}

export function SeatSelectionMap({
  tripId,
  itineraryId,
  maxSeats,
  basePrice,
  onSelectionChange,
}: SeatSelectionMapProps) {
  const [layout, setLayout] = useState<any>(null)
  const [seats, setSeats] = useState<Seat[]>([])
  const [selectedSeats, setSelectedSeats] = useState<string[]>([])
  const [currentFloor, setCurrentFloor] = useState(1)
  const [isLoading, setIsLoading] = useState(true)
  const [error, setError] = useState<string | null>(null)
  const [reservationTimer, setReservationTimer] = useState<number | null>(null)

  // Carregar assentos
  useEffect(() => {
    loadSeats()
    
    // Atualizar a cada 10 segundos
    const interval = setInterval(loadSeats, 10000)
    
    return () => clearInterval(interval)
  }, [tripId, itineraryId])

  // Timer de reserva (5 minutos)
  useEffect(() => {
    if (selectedSeats.length > 0 && !reservationTimer) {
      setReservationTimer(300) // 5 minutos em segundos
    }

    if (reservationTimer && reservationTimer > 0) {
      const timer = setInterval(() => {
        setReservationTimer((prev) => (prev ? prev - 1 : null))
      }, 1000)

      return () => clearInterval(timer)
    }

    if (reservationTimer === 0) {
      // Tempo expirado - limpar seleção
      handleClearSelection()
      alert('Tempo de reserva expirado. Por favor, selecione novamente.')
    }
  }, [reservationTimer, selectedSeats.length])

  const loadSeats = async () => {
    try {
      setIsLoading(true)
      setError(null)

      const response = await fetch(
        `/api/public/trips/${tripId}/seats?itinerary_id=${itineraryId}`
      )

      if (!response.ok) {
        throw new Error('Erro ao carregar assentos')
      }

      const data = await response.json()
      setLayout(data.layout)
      setSeats(data.seats)
    } catch (error) {
      console.error('Erro ao carregar assentos:', error)
      setError('Erro ao carregar mapa de assentos. Tente novamente.')
    } finally {
      setIsLoading(false)
    }
  }

  const handleSeatClick = (seat: Seat) => {
    // Não permitir seleção de assentos não disponíveis
    if (seat.status !== 'available') {
      return
    }

    // Se já está selecionado, remover
    if (selectedSeats.includes(seat.number)) {
      const newSelection = selectedSeats.filter((s) => s !== seat.number)
      setSelectedSeats(newSelection)
      updateParent(newSelection)
      return
    }

    // Verificar limite de assentos
    if (selectedSeats.length >= maxSeats) {
      alert(`Você pode selecionar no máximo ${maxSeats} assento(s)`)
      return
    }

    // Adicionar à seleção
    const newSelection = [...selectedSeats, seat.number]
    setSelectedSeats(newSelection)
    updateParent(newSelection)
  }

  const updateParent = (selection: string[]) => {
    // Calcular preço total
    const total = selection.reduce((sum, seatNumber) => {
      const seat = seats.find((s) => s.number === seatNumber)
      return sum + basePrice + (seat?.extraPrice || 0)
    }, 0)

    onSelectionChange(selection, total)
  }

  const handleClearSelection = () => {
    setSelectedSeats([])
    setReservationTimer(null)
    updateParent([])
  }

  // Organizar assentos em grid
  const getSeatsForFloor = (floor: number) => {
    return seats.filter((s) => s.floor === floor)
  }

  const getSeatAtPosition = (floor: number, row: number, col: number) => {
    return seats.find(
      (s) => s.floor === floor && s.row === row && s.column === col
    )
  }

  // Estatísticas
  const stats = {
    total: seats.filter((s) => s.type === 'seat').length,
    available: seats.filter((s) => s.status === 'available' && s.type === 'seat')
      .length,
    occupied: seats.filter((s) => s.status === 'occupied').length,
    selected: selectedSeats.length,
  }

  if (isLoading) {
    return (
      <Card className="p-8">
        <div className="flex items-center justify-center">
          <div className="animate-spin rounded-full h-12 w-12 border-b-2 border-blue-600" />
        </div>
        <p className="text-center mt-4 text-gray-600">
          Carregando mapa de assentos...
        </p>
      </Card>
    )
  }

  if (error) {
    return (
      <Alert variant="destructive">
        <AlertCircle className="h-4 w-4" />
        <AlertDescription>{error}</AlertDescription>
        <Button onClick={loadSeats} className="mt-4">
          Tentar Novamente
        </Button>
      </Alert>
    )
  }

  if (!layout) {
    return (
      <Alert>
        <AlertDescription>
          Mapa de assentos não disponível para esta viagem.
        </AlertDescription>
      </Alert>
    )
  }

  return (
    <div className="space-y-6">
      {/* ═══════════════════════════════════════════════════════════ */}
      {/* HEADER COM ESTATÍSTICAS */}
      {/* ═══════════════════════════════════════════════════════════ */}
      
      <Card className="p-6">
        <div className="flex items-center justify-between mb-4">
          <h3 className="text-2xl font-bold">Escolha seu(s) Assento(s)</h3>
          
          {reservationTimer && (
            <div className="flex items-center gap-2 text-orange-600">
              <Clock className="h-5 w-5 animate-pulse" />
              <span className="font-bold">
                {Math.floor(reservationTimer / 60)}:
                {String(reservationTimer % 60).padStart(2, '0')}
              </span>
            </div>
          )}
        </div>

        {/* Estatísticas */}
        <div className="grid grid-cols-2 md:grid-cols-4 gap-4">
          <div className="text-center p-3 bg-gray-50 rounded-lg">
            <p className="text-2xl font-bold text-gray-800">{stats.total}</p>
            <p className="text-sm text-gray-600">Total</p>
          </div>
          <div className="text-center p-3 bg-green-50 rounded-lg">
            <p className="text-2xl font-bold text-green-600">
              {stats.available}
            </p>
            <p className="text-sm text-gray-600">Disponíveis</p>
          </div>
          <div className="text-center p-3 bg-red-50 rounded-lg">
            <p className="text-2xl font-bold text-red-600">{stats.occupied}</p>
            <p className="text-sm text-gray-600">Ocupados</p>
          </div>
          <div className="text-center p-3 bg-blue-50 rounded-lg">
            <p className="text-2xl font-bold text-blue-600">{stats.selected}</p>
            <p className="text-sm text-gray-600">Selecionados</p>
          </div>
        </div>

        {/* Alerta de seleção */}
        {selectedSeats.length > 0 && (
          <Alert className="mt-4 bg-blue-50 border-blue-200">
            <Check className="h-4 w-4 text-blue-600" />
            <AlertDescription className="text-blue-800">
              Você selecionou {selectedSeats.length} assento(s):{' '}
              <strong>{selectedSeats.join(', ')}</strong>
              <Button
                size="sm"
                variant="ghost"
                onClick={handleClearSelection}
                className="ml-2"
              >
                <X className="h-3 w-3 mr-1" />
                Limpar
              </Button>
            </AlertDescription>
          </Alert>
        )}
      </Card>

      {/* ═══════════════════════════════════════════════════════════ */}
      {/* MAPA DO VEÍCULO */}
      {/* ═══════════════════════════════════════════════════════════ */}
      
      <Card className="p-8">
        {/* Seletor de Andar (se Double Decker) */}
        {layout.floors === 2 && (
          <div className="flex justify-center gap-2 mb-6">
            <Button
              variant={currentFloor === 1 ? 'default' : 'outline'}
              onClick={() => setCurrentFloor(1)}
            >
              1º Andar
            </Button>
            <Button
              variant={currentFloor === 2 ? 'default' : 'outline'}
              onClick={() => setCurrentFloor(2)}
            >
              2º Andar
            </Button>
          </div>
        )}

        {/* Indicador de Frente */}
        <div className="text-center mb-6">
          <Badge className="bg-blue-600 text-white px-6 py-2">
            ⬆️ FRENTE DO VEÍCULO
          </Badge>
        </div>

        {/* Grid de Assentos */}
        <div className="flex justify-center">
          <div
            className="inline-grid gap-3"
            style={{
              gridTemplateColumns: `repeat(${layout.columns}, 70px)`,
            }}
          >
            {Array.from({ length: layout.rows }).map((_, rowIndex) =>
              Array.from({ length: layout.columns }).map((_, colIndex) => {
                const seat = getSeatAtPosition(currentFloor, rowIndex, colIndex)
                
                if (!seat) {
                  return (
                    <div
                      key={`${rowIndex}-${colIndex}`}
                      className="w-16 h-16"
                    />
                  )
                }

                return (
                  <SeatButton
                    key={seat.id}
                    seat={seat}
                    isSelected={selectedSeats.includes(seat.number)}
                    onClick={() => handleSeatClick(seat)}
                    basePrice={basePrice}
                  />
                )
              })
            )}
          </div>
        </div>

        {/* Legenda */}
        <div className="mt-8 pt-6 border-t">
          <h4 className="font-bold mb-4 text-center">Legenda</h4>
          <div className="grid grid-cols-2 md:grid-cols-5 gap-4">
            <LegendItem
              color="bg-green-500"
              icon={<Check className="h-4 w-4" />}
              label="Disponível"
            />
            <LegendItem
              color="bg-blue-600"
              icon={<Check className="h-4 w-4" />}
              label="Selecionado"
            />
            <LegendItem
              color="bg-red-500"
              icon={<X className="h-4 w-4" />}
              label="Ocupado"
            />

              color="bg-yellow-500"
              icon={<Star className="h-4 w-4" />}
              label="VIP/Premium"
            />
            <LegendItem

              icon={<Lock className="h-4 w-4" />}

        </div>
      </Card>

      {/* ═══════════════════════════════════════════════════════════ */}
      {/* RESUMO DA SELEÇÃO */}
      {/* ═══════════════════════════════════════════════════════════ */}
      
      {selectedSeats.length > 0 && (
        <Card className="p-6 bg-blue-50 border-blue-200">
          <h4 className="font-bold mb-4">📋 Resumo da Seleção</h4>
          
          <div className="space-y-3">
            {selectedSeats.map((seatNumber) => {
              const seat = seats.find((s) => s.number === seatNumber)
              if (!seat) return null

              const seatPrice = basePrice + seat.extraPrice

              return (
                <div
                  key={seatNumber}
                  className="flex items-center justify-between p-3 bg-white rounded-lg"
                >
                  <div className="flex items-center gap-3">
                    <div className="w-10 h-10 bg-blue-600 text-white rounded-lg flex items-center justify-center font-bold">
                      {seatNumber}
                    </div>
                    <div>
                      <p className="font-semibold">Assento {seatNumber}</p>
                      <div className="flex gap-2 mt-1">
                        {seat.isVip && (
                          <Badge className="bg-yellow-500 text-xs">VIP</Badge>
                        )}
                        {seat.isPremium && (
                          <Badge className="bg-purple-500 text-xs">
                            Premium
                          </Badge>

                          <Badge className="bg-blue-500 text-xs">
                            Acessível
                          </Badge>
                        )}
                      </div>
                    </div>
                  </div>

                  <div className="text-right">
                    <p className="font-bold text-lg text-green-600">
                      R$ {seatPrice.toFixed(2)}
                    </p>

                      <p className="text-xs text-gray-600">
                        +R$ {seat.extraPrice.toFixed(2)}
                      </p>
                    )}
                  </div>
                </div>
              )
            })}
          </div>

          <div className="mt-4 pt-4 border-t border-blue-200">
            <div className="flex items-center justify-between">
              <span className="text-lg font-bold">Total:</span>
              <span className="text-2xl font-bold text-green-600">
                R${' '}
                {selectedSeats
                  .reduce((sum, seatNumber) => {
                    const seat = seats.find((s) => s.number === seatNumber)
                    return sum + basePrice + (seat?.extraPrice || 0)
                  }, 0)
                  .toFixed(2)}
              </span>
            </div>
          </div>
        </Card>
      )}
    </div>
  )
}

function SeatButton({
  seat,
  isSelected,
  onClick,
  basePrice,
}: {
  seat: Seat
  isSelected: boolean
  onClick: () => void
  basePrice: number
}) {
  // Não renderizar se não for assento
  if (seat.type !== 'seat') {
    return <NonSeatElement seat={seat} />
  }

  // Determinar cor e estado
  const getButtonStyle = () => {
    if (isSelected) {
      return 'bg-blue-600 text-white border-2 border-blue-800 shadow-lg scale-105'
    }

    switch (seat.status) {
      case 'available':
        if (seat.isVip || seat.isPremium) {
          return 'bg-yellow-500 text-white hover:bg-yellow-600 border-2 border-yellow-600'
        }
        return 'bg-green-500 text-white hover:bg-green-600 border-2 border-green-600'
      
      case 'occupied':
        return 'bg-red-500 text-white cursor-not-allowed opacity-60'
      
      case 'reserved':
        return 'bg-orange-500 text-white cursor-not-allowed opacity-60'
      
      case 'blocked':
        return 'bg-gray-400 text-white cursor-not-allowed opacity-60'
      
      default:
        return 'bg-gray-200'
    }
  }

  const isClickable = seat.status === 'available'

  const seatPrice = basePrice + seat.extraPrice

  return (
    <TooltipProvider>
      <Tooltip>
        <TooltipTrigger asChild>
          <button
            onClick={onClick}
            disabled={!isClickable}
            className={`
              w-16 h-16 rounded-lg flex flex-col items-center justify-center
              transition-all duration-200 font-bold
              ${getButtonStyle()}
              ${isClickable ? 'cursor-pointer' : 'cursor-not-allowed'}
            `}
          >
            {/* Ícones especiais */}
            <div className="flex gap-1 mb-1">
              {seat.isVip && <Star className="h-3 w-3" />}
              {seat.isAccessible && <Accessibility className="h-3 w-3" />}
            </div>

            {/* Número do assento */}
            <span className="text-sm">{seat.number}</span>

            {/* Checkmark se selecionado */}
            {isSelected && <Check className="h-4 w-4 mt-1" />}
          </button>
        </TooltipTrigger>
        
        <TooltipContent className="bg-gray-900 text-white p-4">
          <div className="space-y-2">
            <p className="font-bold">Assento {seat.number}</p>
            
            <div className="space-y-1 text-sm">
              <p>
                Status:{' '}
                <span className="font-semibold">
                  {seat.status === 'available' && '✅ Disponível'}
                  {seat.status === 'occupied' && '❌ Ocupado'}
                  {seat.status === 'reserved' && '⏳ Reservado'}
                  {seat.status === 'blocked' && '🔒 Bloqueado'}
                </span>
              </p>

              {seat.status === 'available' && (
                <p>
                  Preço:{' '}
                  <span className="font-bold text-green-400">
                    R$ {seatPrice.toFixed(2)}
                  </span>
                </p>
              )}

              {seat.extraPrice > 0 && (
                <p className="text-yellow-400">
                  +R$ {seat.extraPrice.toFixed(2)} (adicional)
                </p>
              )}

              {seat.isVip && (
                <p className="text-yellow-400">⭐ Assento VIP</p>
              )}

              {seat.isPremium && (
                <p className="text-purple-400">💎 Assento Premium</p>
              )}

              {seat.isAccessible && (
                <p className="text-blue-400">♿ Assento Acessível</p>
              )}

              {seat.notes && (
                <p className="text-gray-300 italic">{seat.notes}</p>
              )}
            </div>
          </div>
        </TooltipContent>
      </Tooltip>
    </TooltipProvider>
  )
}

function NonSeatElement({ seat }: { seat: Seat }) {
  const getStyle = () => {
    switch (seat.type) {
      case 'wc':
        return 'bg-purple-500 text-white'
      case 'stairs':
        return 'bg-gray-800 text-white'
      case 'fridge':
        return 'bg-cyan-500 text-white'
      case 'driver':
        return 'bg-yellow-500 text-white'
      case 'empty':
        return 'bg-transparent'
      default:
        return 'bg-gray-200'
    }
  }

  const getIcon = () => {
    switch (seat.type) {
      case 'wc':
        return <Toilet className="h-6 w-6" />
      case 'stairs':
        return <Stairs className="h-6 w-6" />
      case 'fridge':
        return <Refrigerator className="h-6 w-6" />
      default:
        return null
    }
  }

  const getLabel = () => {
    switch (seat.type) {
      case 'wc':
        return 'WC'
      case 'stairs':
        return 'Escada'
      case 'fridge':
        return 'Frigobar'
      case 'driver':
        return '🚗'
      default:
        return ''
    }
  }

  if (seat.type === 'empty') {
    return <div className="w-16 h-16" />
  }

  return (
    <div
      className={`
        w-16 h-16 rounded-lg flex flex-col items-center justify-center
        ${getStyle()}
      `}
    >
      {getIcon()}
      <span className="text-xs font-bold mt-1">{getLabel()}</span>
    </div>
  )
}

'use client'

import { Button } from '@/components/ui/button'

export function ReservationWizard({ trip, itinerary }: any) {
  const [currentStep, setCurrentStep] = useState(1)
  const [formData, setFormData] = useState({
    // Step 1: Dados pessoais
    name: '',
    cpf: '',
    email: '',
    phone: '',
    birthdate: '',
    
    // Step 2: Assentos
    selectedSeats: [] as string[],
    totalPrice: 0,
    
    // Step 3: Pagamento
    paymentMethod: '',
  })

  const handleSeatSelection = (seats: string[], totalPrice: number) => {
    setFormData({
      ...formData,
      selectedSeats: seats,
      totalPrice,
    })
  }

  const handleNext = () => {
    // Validações por step
    if (currentStep === 1) {
      if (!formData.name || !formData.cpf || !formData.email) {
        alert('Preencha todos os campos obrigatórios')
        return
      }
    }

    if (currentStep === 2) {
      if (formData.selectedSeats.length === 0) {
        alert('Selecione pelo menos um assento')
        return
      }
    }

    setCurrentStep(currentStep + 1)
  }

  const handleBack = () => {
    setCurrentStep(currentStep - 1)
  }

  return (
    <div className="max-w-6xl mx-auto">
      {/* Progress Bar */}
      <div className="mb-8">
        <div className="flex items-center justify-between">
          {[1, 2, 3, 4].map((step) => (
            <div
              key={step}
              className={`flex-1 h-2 mx-1 rounded-full transition-all ${
                step <= currentStep ? 'bg-blue-600' : 'bg-gray-200'
              }`}
            />
          ))}
        </div>
        <div className="flex justify-between mt-2 text-sm">
          <span className={currentStep >= 1 ? 'text-blue-600 font-bold' : 'text-gray-400'}>
            1. Dados
          </span>
          <span className={currentStep >= 2 ? 'text-blue-600 font-bold' : 'text-gray-400'}>
            2. Assentos
          </span>
          <span className={currentStep >= 3 ? 'text-blue-600 font-bold' : 'text-gray-400'}>
            3. Pagamento
          </span>
          <span className={currentStep >= 4 ? 'text-blue-600 font-bold' : 'text-gray-400'}>
            4. Confirmação
          </span>
        </div>
      </div>

      {/* Step Content */}
      <div className="mb-8">
        {currentStep === 1 && (
          <PersonalDataForm data={formData} onChange={setFormData} />
        )}

        {currentStep === 2 && (
          <SeatSelectionMap
            tripId={trip.id}
            itineraryId={itinerary.id}
            maxSeats={formData.passengersCount || 1}
            basePrice={Number(trip.promotional_price || trip.price_per_person)}
            onSelectionChange={handleSeatSelection}
          />
        )}

        {currentStep === 3 && (
          <PaymentForm data={formData} onChange={setFormData} />
        )}

        {currentStep === 4 && (
          <ConfirmationStep data={formData} trip={trip} />
        )}
      </div>

      {/* Navigation Buttons */}
      <div className="flex justify-between">
        {currentStep > 1 && (
          <Button variant="outline" onClick={handleBack}>
            <ArrowLeft className="h-4 w-4 mr-2" />
            Voltar
          </Button>
        )}

        {currentStep < 4 && (
          <Button onClick={handleNext} className="ml-auto">
            Próximo
            <ArrowRight className="h-4 w-4 ml-2" />
          </Button>
        )}

        {currentStep === 4 && (
          <Button onClick={handleSubmit} className="ml-auto bg-green-600">
            Confirmar Reserva
          </Button>
        )}
      </div>
    </div>
  )
}
